# ZOND Labs — официальный промосайт

Адаптивная презентационная страница ZOND Labs по утверждённому макету: тёмный технологичный первый экран, светлый блок xDot, собственная разработка, точечная цифровая типографика, направления и единый футер.

## Локальный запуск

Нужен Node.js версии 18 или новее. Установка `pnpm` и `npm install` **не требуется**.

```bash
cd ~/Desktop/zondlabs
git pull --ff-only origin main
PORT=5174 node server.mjs
```

На MacBook: http://localhost:5174

На iPhone: в той же Wi-Fi-сети открыть `http://IP_МАКБУКА:5174`. IP на MacBook можно узнать командой `ipconfig getifaddr en0`. Для подключения с телефона сервер слушает `0.0.0.0`.

Порт 5173 можно оставить для SKP; ZOND Labs использует 5174.

## Структура

- `index.html` — доступная семантическая разметка, метаданные, формы поиска, галерея и диалоги.
- `styles.css` — адаптивные стили, верные исходному дизайн-макету.
- `script.js` — слайдер, галерея с предзагрузкой, SVG-точечные цифры, навигация, поиск и диалоги.
- `server.mjs` — простой сервер статических файлов, поддерживает GET/HEAD, ошибки, основные заголовки безопасности.
- `assets/` — локальные изображения и Open Graph-изображение для соцсетей.
- `AUDIT_FIXES.md` — внесённые исправления и ограничения.

## Продукт и контакты

xDot находится в стадии разработки. Изображения — концептуальные рендеры, а не фотографии серийного устройства. Интернет-магазин, аккаунты, онлайн-оплата и служба поддержки **не подключены**. На сайте нет кнопок, которые выдавали бы себя за действующую покупку, личный кабинет или службу поддержки. В футере указан фактический статус каналов связи. GitHub-ссылка — на публичный репозиторий сайта, а не на службу клиентской поддержки.

## Медиа и публикация

Некоторые изображения в утверждённом макете изначально были небольшими фрагментами концепт-иллюстрации: масштабирование не восстановит отсутствующие детали. Рендеры присланного футляра переэкспортированы из исходных файлов с меньшими потерями. Для фотореалистичного качества на Retina нужны оригинальные полноразмерные 3D-рендеры устройства.

Перед запуском на домене добавьте фактические контакты, юридические страницы и при необходимости `sitemap.xml` с реальным доменом. `og:image` сейчас указывает на публичный медиафайл в этом репозитории.
