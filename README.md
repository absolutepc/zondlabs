# ZOND Labs — сайт компании

Адаптивная промо-страница ZOND Labs по утверждённому макету. Оригинальный интерфейс на HTML/CSS/JS, локальные изображения, цифры в формате SVG dot-matrix, интерактивная галерея и адаптивное меню.

## Запуск

Требуется Node.js 18+. Никакие дополнительные пакеты не нужны.

```bash
cd zondlabs-website
PORT=5174 node server.mjs
```

Открыть http://localhost:5174. Порт 5173 оставлен под SKP.

## Состав

- `index.html` — структура и контент;
- `styles.css` — оформление и адаптивная сетка;
- `script.js` — dot-matrix, меню, смена изображений и диалоги;
- `assets/` — локальные фирменные визуалы.

## Статус

Концепт промосайта. xDot находится в разработке. Покупка, личный кабинет, приём платежей и фактическая поддержка ещё не подключены. Показанные рендеры иллюстрируют дизайн и могут отличаться от серийного устройства.
